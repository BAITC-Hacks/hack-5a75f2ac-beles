# HACKALEM AI

Локальная демоверсия подбора подрядчиков для мероприятий в Казахстане.
React + TypeScript + Node.js 24. Для ИИ используется OpenAI Responses API,
модель `gpt-4.1-mini`, `temperature: 0`, структурированный JSON.
Подрядчики в `data/contractors.json` вымышлены и помечены `synthetic: true`.

## Самый простой запуск на Windows

1. Откройте папку проекта в Проводнике.
2. Откройте файл `.env` в Блокноте. Если файла нет, скопируйте `.env.example` и назовите копию `.env`.
3. После `OPENAI_API_KEY=` вставьте свой ключ OpenAI API и сохраните файл.
   Ключ создаётся на https://platform.openai.com/api-keys в том проекте, которому доступны ваши кредиты.
   Не отправляйте ключ в чат и не добавляйте в переменные `VITE_*`.
4. Дважды нажмите `start.cmd`. При первом запуске нужен интернет для установки зависимостей.
5. Дождитесь сообщения `Open http://localhost:3000` и откройте этот адрес в браузере.
6. Не закрывайте окно запуска, пока пользуетесь сайтом. Для остановки нажмите `Ctrl+C`.

Скрипт использует Node.js из установленного Codex, если он доступен, либо обычный Node.js 24.
На другом компьютере без Node.js установите версию 24 с https://nodejs.org.
Без ключа форма и карта работают, а поиск показывает сообщение о недоступности сервиса ИИ.
После изменения ключа остановите приложение и запустите `start.cmd` заново.

Пример поиска: **Алматы → 15.10.2026 → Площадки → Свадьба → 350000 ₸**.
Для проверки отказа укажите бюджет **1000 ₸**. Оба поиска требуют рабочего API-ключа.

## Docker и Caddy (необязательный вариант)

Если установлен и запущен Docker Desktop, из папки проекта выполните:

```sh
docker compose up -d --build
```

Откройте http://localhost:8080. Compose собирает приложение и запускает соседний
контейнер Caddy, который перенаправляет запросы к приложению. Порт приложения
наружу не публикуется; порт Caddy доступен только на этом компьютере.

```sh
docker compose logs -f
docker compose down
```

Локально используется HTTP. Публичный HTTPS пока не настроен: домена и VPS нет.
Когда они появятся, Caddy можно настроить на доменное имя и порты 80/443 с
автоматическими сертификатами. Перед публичным запуском нужны доступ к приложению
и лимиты расходов; текущая конфигурация предназначена для локальной демонстрации.

## Данные и подбор

- Данные читаются из `data/contractors.json`. Переменная `CONTRACTORS_FILE` позволяет выбрать другой файл при обычном запуске.
- Из списка исключаются занятые в выбранную дату, другой город/категория и цена выше бюджета на 10%.
- Из оставшихся выбираются пять: сначала совпадение формата, затем меньшая цена.
- OpenAI выбирает до трёх ID и объясняет выбор по описаниям. Сервер возвращает оригинальные данные подрядчиков.
- Если кандидатов нет, OpenAI формирует вежливый отказ.
- В сервере установлен общий лимит 20 поисковых запросов в минуту и ограничение ответа ИИ в 1200 токенов.
- Ключ хранится только на сервере. `.env` исключён из Git и Docker build context.
- PostgreSQL пока не нужен: редактирование и постоянное хранение новых записей через сайт не реализованы.

## Проверки и разработка

С установленным Node.js 24 и npm:

```sh
npm exec --yes --package=pnpm@11.19.0 -- pnpm install --frozen-lockfile
npm exec --yes --package=pnpm@11.19.0 -- pnpm test
npm exec --yes --package=pnpm@11.19.0 -- pnpm build
node --env-file-if-exists=.env server.ts
```

Тесты используют имитацию OpenAI и не расходуют кредиты.
Для разработки интерфейса запустите `pnpm dev` параллельно с сервером на порту 3000.

Документация: [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs),
[GPT-4.1 mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini),
[Caddy Automatic HTTPS](https://caddyserver.com/docs/automatic-https).
